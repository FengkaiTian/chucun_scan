# 标普500 信号扫描器 · 回测复盘报告

数据：2022-12 至 2026-11 共 2,908 个基础信号（MACD 柱零轴下收窄 + RSI<30 回升），其中 2,880 个已有 T+10 结果；2026 年为样本外（组合是用 2020–2025 年数据挑出来的）。收益均从信号次日收盘起算，超额 = 个股收益 − 同期标普500。

## 一句话结论
**信号本身只有很弱的优势，评级基本不增加价值，大跌多数无法提前预警，唯一稳健的风险信号是“财报落在持仓期”。** 把表里的胜率打折看，仓位别重。

## 1. 声称 vs 实际
| | 声称 T+5 胜率 | 实际上涨比例（样本内 / 2026） | T+5 超额（样本内 / 2026） |
|---|---|---|---|
| 验证组合（现行推荐，去重） | 65–80% | 60% / 58% | +0.47% / +0.01%（均不显著） |
| 只过基础信号（对照） | — | 57% / 55% | +0.17% / −0.08% |
| 仅 SSS 级 | 74% | 67% / 73%（n=171/70） | +1.46% / +0.42%（弱） |

落差主要是**选择偏差**：从 1626 个组合里挑赢家，纯噪音下最优 1% 也能到 ~75%。样本内就已经低于声称值，不是 2026 才变差。约 70% 的收益来自大盘本身涨跌。

## 2. 把所有规则都试了一遍
- 穷举 **32,434 条规则**（271 条单条 + 32,163 条两两组合，覆盖 27 个数值特征各 4 个分位、37 个条件、板块、星期、财报、评级），按信号日聚类检验，用“打乱标签的最大统计量”做多重检验校正，再看 2026 样本外能否复现。
- 目标“T+5 超额”：**只有 1 条规则通过校正**——“大盘 5 日跌 ≥1.58% 且当天全市场 ≥19 只股票同时触发”，样本内超额 +2.76%（n=130），2026 年 +0.99%（n=31）。但这 161 条信号只来自 **6 个交易日、约 5 次事件**（2024-12、2025-01、2025-03、2025-11、2026-03），无法和运气区分，只能当参考。
- 名义上显著（|t|≥2）的 6,166 条规则，样本外方向一致的只有 53%（纯噪音 50%）→ 基本是噪音。
- 目标“大跌（T+5≤−5% 或 T+10≤−8%）”：0 条通过校正。

## 3. 为什么大跌 / 为什么超预期
- **大跌**：①财报在持仓期，大跌比例 2026 年约 28% vs 10%（有评级和无评级的股票都一致）；②财报后的下跌中继 + 高波动（FIX：距高点 −38%、ATR 7.2%）；③大盘同时重挫（11/4–11/5）。CAT 属于①，入场后第 5 个交易日财报跌 9.3%。
- **超预期**：多数是真超额而不是大盘反弹（赢家超额中位数 +5~6%）；高 ATR（≥4）大赢率翻倍（23% vs 8%），但大跌率也翻倍（16% vs 8%）——只是方差大；当天全市场信号 ≥5 只（大盘整体超卖）时更好，孤立信号偏弱。
- 统计上不稳、不要采信：大盘在 200 日线下更好、近 20 日跌幅≥15% 更好、距高点 −35% 且高 ATR 必跌、板块、放量、跳空。

## 4. 出场方式（同一批信号，样本内 / 2026，平均收益）
| 方式 | 平均收益 | 大亏比例（≤−5%） |
|---|---|---|
| 固定持有 5 日 | +0.62% / +0.75% | 7.5% / 9.3% |
| 固定持有 10 日 | +1.02% / +2.00% | 13.4% / 13.6% |
| 止损 −4%，最长 5 日 | +0.52% / +0.36% | 1.1% / 2.9% |
| 止盈 +4%，最长 10 日 | +0.84% / +0.99%（上涨比例 65% / 68%） | 11.5% / 11.5% |
- 持有更久平均收益更高，代价是大亏更多。
- 只有紧止损（−4%）能明显压低大亏，代价是少赚 0.1–0.4 个点；更宽的止损在跳空时形同虚设。
- 止盈能提高上涨比例，但砍掉了大赢，平均收益低于不止盈。
- **现行止损价（MA20×0.97）对约 91% 的信号高于入场价**（超卖股票通常本来就低于均线），按它设止损等于入场即触发，基本没有意义。

## 5. 选股方式（T+5，去重，样本内 / 2026 超额）
| 方式 | 超额 | 大跌率 |
|---|---|---|
| 验证组合（现行） | +0.47% / +0.01% | 9% / 12% |
| 验证组合 + 无财报 + 当天≥5只 | +0.77% / +0.27% | 6% / 7% |
| 基础信号 + 无财报 + 当天≥5只 | +0.31% / +0.59% | 8% / 6% |
| 每天只取胜率最高 1 只 | +0.61% / +0.10% | 10% / 14% |
| 每天取胜率最高 3 只 | +0.57% / −0.31% | 10% / 15% |

没有任何一种按“信号日”聚类后统计显著（|t|<2），叠加“无财报 + 当天≥5只”方向最稳，大跌率最低。

## 6. 建议
1. **推荐时附带**（已加到页面）：财报是否在持仓期、ATR%、当天全市场信号数；胜率按实测 ~58–60% 看。
2. **仓位**：财报在持仓期的回避或减半；ATR≥4 减半；“无财报 + 当天≥5只”的信号可优先。
3. **止损**：建议把 MA20×0.97 换成“入场价 −4%”，或干脆不显示（需要你决定，我没动）。
4. **不要**把上面任何规则做成硬过滤——误杀率 55–60%，统计上都不显著。
5. 评级只保留 SSS 作弱加分；A、B 级与对照组没有可靠差别。

## 局限
成分股用今天的名单（幸存者偏差）；2026 样本外只有约 1 年且信号扎堆，独立事件数很少；收益用日线收盘价，止损按日内最低价成交，未计滑点和手续费；约 9% 的信号缺财报字段。
