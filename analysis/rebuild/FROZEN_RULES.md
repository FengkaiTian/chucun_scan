# 冻结的规则和复核日期（2026-11-18 冻结）

冻结之后，在复核日期之前**不改规则、不调参数、不加过滤条件**。2025–2026 年的数据已经看过，只用于诊断，不算验证。

## 1. 深跌规则（`forward_track.py`，记录到 `forward_log.csv`）
| 规则 | 条件 | 交易 |
|---|---|---|
| R1 纯深跌 | 收盘 < MA200 × 0.75 | 次日收盘买入，持有 20 个交易日；同一股票 20 个交易日内只记一次 |
| R2 深跌+缩量 | R1，且当日成交量 < 此前 20 日（不含当日）均量 × 0.70 | 同上 |

- 成绩口径：扣 0.10% 来回成本；基准是同一进出日期的 SPY（含分红）。
- 股票池：运行当天的标普500 成分股。
- 已知：在回测里，缩量相对"同日、深跌幅度和贝塔相近、但没缩量"的对照没有增量（两期差都≈0，区间跨 0）。**R2 只作观察，不作为加分条件。**
- 复核日期：
  - **2027-05-18（中期）**：只检查数据和执行有没有问题，不下结论。
  - **2027-11-18（正式）**：R1 累计 ≥150 笔，且每笔净超额（相对同期 SPY）> 0、按月分块的 95% 区间下限 > −0.5%，才继续；否则停止这条研究。

## 2. 五日星级（`daily_scan.py`，记录到 `picks_history.json`）
| 星级 | 规则 |
|---|---|
| ★★★ | 基础信号 + 跳空收正 |
| ★★ | 基础信号 + 十字星底 |
| ★ | 其余命中 SSS 组合的 |
| 参考 | 其他基础信号 |

- 复核节点：★★★ 和 ★★ 合计 **≥50 笔**时复核。
- 主要看：相对**同日普通信号（参考档）**的扣费后 5 日收益差，其次看胜率（≥58%）。
- 达不到就退回"只看 SSS"。
