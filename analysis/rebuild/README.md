# 20 年组合搜索：数据准备

`python prepare_data.py` 生成 `data/`，大约 5 分钟。`--no-download` 只重算，不重新下载。`python verify_conditions.py` 用来抽样核对。

| 文件 | 内容 |
|---|---|
| `membership.csv.gz` | 时点成分股：每个月末的名单，2005-12 至今，用维基变更表往回推 |
| `ohlcv_*.parquet` | 643 只股票的日线，2005-01 至今，已复权 |
| `index_gspc / index_vix.parquet` | 标普500、VIX |
| `ew_index.parquet` | 当时成分股的等权日收益，用作另一种基准 |
| `signals_20y.parquet` | 全部基础信号 15,197 条，每条带 37 个条件、辅助指标、远期收益、市场环境 |
| `coverage.csv` | 每年成分股里有行情的比例 |
| `download_failed.csv` | 下载不到的 206 只，多数已退市 |

## signals_20y.parquet 主要字段

- `base` 和 37 个条件：bool 值，定义与 `daily_scan.compute_conditions` 逐条一致。
- `in_index`：信号日所在月份的上个月末，这只股票是否在指数内。分析时只用 `True` 的。
- `r1/3/5/10/20`：入场后第 n 天的收益（%），入场价是信号次日收盘价，与页面一致。
- `s1/3/5/10`：从信号日收盘价起算的收益。
- `b*`：同期标普500 收益；`x* = r* − b*`。
- `mae5/10, mfe5/10`：持有期内的最低点和最高点，相对入场价。
- `gap_next_open`：入场日开盘相对信号日收盘的跳空幅度。
- `vix, spx_dist_ma200, spx_ret5d, n_base_day, n_base_day_idx`：市场环境。

## 核对结果

- **base 信号：** 抽 1,500 个信号日加 1,500 个随机日，不一致 3 个（0.1%）。
- **37 个条件：** 在 1,503 条信号上逐条核对，全部一致。
- **和旧数据集对比：** `../signals_dataset.csv`（2022-12 起）的 2,908 条全部包含在新数据里。

## 局限

- 早年行情覆盖率较低：2006 年 71%，2015 年 81%，2025 年 98%。缺的多是退市股，所以早年仍有幸存者偏差，结论会偏乐观。
- 没有历史财报日期。
- 只有日线，没计滑点。
